(https://openfontlicense.org): Fraunces, Inter, Playfair Display, Karla, DM Serif Display, DM Sans,
Oswald, Space Grotesk, Cormorant Garamond, Manrope, JetBrains Mono. Latin subset, woff2,
committed so builds never depend on a network fetch (next/font/local self-hosts them exactly
